# Blender 快速分镜设计系统

基于 Blender 的快速分镜（Previs/Storyboard）设计插件，服务个人创作者的前期镜头设计工作流。

## 功能

- 三维视口搭简模、打相机、摆构图
- 一键出图（静帧 + 缩略图）
- 宫格视图浏览全部镜头，拖拽排序
- 时间线视图按镜头时长横向铺排
- 排序/时长修改写回项目数据，自动串片（animatic）

## 技术架构

- **UI**: pywebview 伴生窗口（宫格 + 时间线）
- **数据层**: SQLite + 本地 HTTP 服务（127.0.0.1）
- **镜头组织**: 一镜头一场景（Scene），元数据挂 Scene 自定义属性
- **出图**: Workbench/EEVEE 低采样渲染
